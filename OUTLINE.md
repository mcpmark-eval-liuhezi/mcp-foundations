# MCP Foundations — Course Outline

A self-paced, three-module onboarding course on the Model Context Protocol (MCP). Each module is anchored on a video from an active MCP educator and closes with a 100-point assignment, due one week apart starting Monday **2026-10-26**.

---

## Module 1: MCP In 26 Minutes (Model Context Protocol)

- **Source video:** https://www.youtube.com/watch?v=kOhLoixrJXo
- **Channel:** Tina Huang (https://www.youtube.com/@tinahuang1)
- **Published:** 2025-10-15 · **Length:** 26m 23s

### What you'll learn

What the Model Context Protocol is and why Anthropic created it, using the "USB-C for AI" analogy; the fundamentals of how MCP works under the hood; the three primitives every MCP server exposes — tools, resources, and prompt templates; the MCP communication life cycle; and how to build your own MCP server both no-code and with code (a Python Google Sheets & Forms server tested with MCP Inspector and registered in Claude Desktop). Four in-video quizzes check your understanding along the way.

## Module 2: Claude's Model Context Protocol is here... Let's test it

- **Source video:** https://www.youtube.com/watch?v=HyzlYwjoXOQ
- **Channel:** Fireship (https://www.youtube.com/@fireship)
- **Published:** 2025-03-31 · **Length:** 8m 8s

### What you'll learn

A fast, code-first reinforcement of Module 1: why MCP is described as "USB-C for AI," and a hands-on build of a TypeScript MCP server that gives an AI model additional context and the ability to modify server data. You'll go from concept to a working server in about eight minutes.

## Module 3: you need to learn MCP RIGHT NOW!! (Model Context Protocol)

- **Source video:** https://www.youtube.com/watch?v=GuTcle5edjk
- **Channel:** NetworkChuck (https://www.youtube.com/@networkchuck)
- **Published:** 2025-09-12 · **Length:** 38m 40s

### What you'll learn

A production-tilted, hands-on deep dive: running MCP servers inside Docker containers; connecting three different clients (Claude Desktop, LM Studio for local models, and Cursor); building your own custom MCP servers; a Kali Linux / security-focused MCP example; and the Docker MCP Gateway, including running it with n8n.
